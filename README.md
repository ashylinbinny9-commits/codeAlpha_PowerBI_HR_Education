# Task 2 – Human Resources Analytics

## Objective

To create an interactive dashboard that analyzes employee performance, satisfaction, recruitment and employee turnover.

## Key Analysis

- Total employees
- Current employees
- Employee attrition
- Attrition rate
- Employee satisfaction
- Employee performance
- Average salary
- Recruitment applications
- Shortlisted candidates
- Interviewed candidates
- Offers and joined employees
- Department-wise analysis

## Power BI Visualizations

The dashboard contains:

- KPI Cards
- Department-wise employee chart
- Attrition by department
- Average performance by department
- Recruitment trend
- Satisfaction vs Performance scatter chart
- Interactive slicers

## Dataset

The HR dataset contains employee information such as:

- Employee ID
- Department
- Job Role
- Gender
- Age
- Satisfaction Score
- Performance Score
- Years at Company
- Overtime
- Monthly Salary
- Employment Status

# Task 4 – Educational Performance and Resource Allocation

## Objective

To develop a dashboard that evaluates student academic performance and helps analyze educational resource utilization.

## Key Analysis

- Total students
- Average marks
- Average CGPA
- Attendance percentage
- Students with backlogs
- Study hours
- Department-wise performance
- Resource allocation
- Resource utilization

## Power BI Visualizations

The dashboard contains:

- KPI Cards
- Average marks by department
- Average CGPA by department
- Students by department
- Study hours vs marks
- Backlogs by department
- Student performance table
- Resource allocation chart
- Interactive department and gender filters

## Dataset

The student dataset contains:

- Student ID
- Student Name
- Department
- Gender
- Age
- Subject marks
- Overall marks
- CGPA
- Attendance
- Study hours
- Backlogs
